# Day 33 – Build a Media Integrity Analyzer

## 📌 Challenge
Built a **Media Integrity Analyzer** using Claude to help users evaluate headlines and emotional manipulation before believing or sharing online content.

## 🚀 What I Built
- Interactive Media Integrity Analyzer
- Headline Accuracy Detector
- Emotion Detection Challenge
- Source Reliability Analysis
- Media Integrity Dashboard
- Responsive single-file HTML application
- Built with HTML, CSS and JavaScript (offline, no external libraries)

## 🧠 Key Learnings
- Not every attention-grabbing headline is misleading.
- Emotional triggers like urgency and FOMO influence decisions.
- Always compare headlines with the actual article.
- Critical thinking is more important than reacting emotionally.
