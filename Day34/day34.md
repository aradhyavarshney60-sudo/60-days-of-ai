# 🕵️ Day 34 – Marketing Detective

## Overview

Marketing Detective is an interactive detective-style web application built as part of the **60 Days AI Challenge (Day 34)**.

The project transforms marketing case studies into an engaging investigation game. Users examine campaign metrics, customer feedback, performance data, and hidden clues to identify the primary marketing mistake behind each failed campaign.

After solving each case, the application provides a detailed learning report explaining the correct diagnosis, supporting evidence, and recommended improvements.

---

## Features

- 🕵️ Detective-themed interactive UI
- 📁 Multiple marketing case studies
- 📌 Evidence-based clue system
- 📊 Campaign performance dashboard
- ✅ Interactive verdict selection
- 📖 Detailed learning reports
- 🎨 Smooth animations and modern design
- 📱 Responsive interface
