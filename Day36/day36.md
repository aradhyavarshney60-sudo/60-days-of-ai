# Day 36 – Cognitive Pattern Explorer

## Project Overview
Built an interactive psychology-inspired web application called **Cognitive Pattern Explorer** using Claude AI. The application helps users explore their decision-making and thinking patterns through interactive scenarios, drag-and-drop activities, and a personalized reflection journal.

## Features
- Calm and Stress mode selection
- Interactive thinking style scenarios
- Drag-and-drop priority sorting
- Thinking pattern mapping with sliders
- Personalized reflection journal
- Progress tracking across chapters
- Responsive single-file HTML application
- Fully offline functionality

## Technologies Used
- HTML5
- CSS3
- Vanilla JavaScript

## Key Learnings
- Designed interactive self-reflection experiences
- Implemented drag-and-drop interactions
- Created multi-step user flows
- Generated personalized results dynamically
- Built a responsive single-file web application using Claude AI
