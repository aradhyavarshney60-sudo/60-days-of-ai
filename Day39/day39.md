# Day 39 – PDF Splitter & Merger

## Project Overview
Built a browser-based PDF Splitter & Merger application using HTML, CSS, and JavaScript. The application processes PDF files locally in the browser, allowing users to split and merge PDFs securely without uploading files to any server.

## Features
- Upload PDF files using drag & drop
- Split PDF using multiple methods
  - Custom page ranges
  - Split every N pages
  - Split after selected pages
  - Extract selected pages
- Merge multiple PDF files
- Page preview before processing
- Download processed PDF files
- Responsive modern UI
- Client-side processing for privacy
