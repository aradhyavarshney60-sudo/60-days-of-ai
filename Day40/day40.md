# Day 40 - Build Your Own AI Assistant

## Project
**Scanline – AI ATS Resume Checker**

An AI-inspired browser-based ATS Resume Scanner that compares a resume against a job description and provides an ATS compatibility score with keyword matching and improvement suggestions.

## Features

- ATS Resume Score (0–100)
- Resume vs Job Description keyword matching
- Pass / Fail verdict
- Missing keyword detection
- Resume improvement suggestions
- Responsive modern UI
- Dark cyber-inspired theme
- Offline browser support
- Pure HTML, CSS and JavaScript

## Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla)
- Local Browser Storage

## How It Works

1. Upload or paste resume text.
2. Paste the job description.
3. Click **Run ATS Scan**.
4. The scanner analyzes keyword overlap, structure, and formatting.
5. View ATS score, matched keywords, missing skills, and suggested improvements.
