# Day 42 – Personal Financial Command Center

## Overview
Built an AI-inspired Personal Financial Command Center as a single-page HTML application. The dashboard helps users track income, spending, savings goals, cash flow, and financial health through an interactive interface.

## Features
- Overview Dashboard
- Weekly Income & Spending Tracker
- Budget & Expense Management
- Savings Goal Tracker
- Weekly Cash Flow Visualization
- What-If Financial Simulator
- Financial Calculators
- Tips & Checklist
- Weekly Financial Report
- Responsive UI
- Local Storage Support
- Dark/Light Mode
- Print Report Option

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Local Storage

## What I Learned
- Creating a complete financial dashboard using HTML, CSS, and JavaScript.
- Managing application state with Local Storage.
- Building interactive forms and financial calculators.
- Designing responsive dashboard layouts.
- Visualizing financial data with charts and progress indicators.
- Improving user experience through organized navigation and reports.
