# 🚀 Day 51/60 - BuildPath | AI-Powered Project Building Copilot

Today marks the beginning of my 10-Day AI Capstone as part of the AB Talks 60-Day Claude AI Challenge.

For this capstone, I am building **BuildPath**, an AI-powered web application designed to help students and self-taught developers turn a project idea into a realistic, personalized, and trackable build plan.

## 💡 The Problem

One of the biggest challenges when learning software development is not always writing the code.

It is deciding:

- What should I build first?
- What should I learn before starting?
- How should I break this project into smaller tasks?
- Which skills am I missing?
- What should I do next?
- How do I keep track of my progress?

Generic tutorials and study planners often provide information, but they don't understand the specific project a developer is trying to build.

This creates a gap between:

**Learning → Planning → Building**

BuildPath is designed to close that gap.

---

## 🎯 The Solution

BuildPath acts as an AI co-pilot for project development.

A user starts with a simple project idea.

For example:

> "I want to build an AI-powered study assistant."

BuildPath then asks a few guided questions about:

- Current skill level
- Available time
- Technical preferences
- Project constraints
- Development experience

The AI uses this information to create a personalized project roadmap.
